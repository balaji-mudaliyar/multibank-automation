# Playwright Framework

This repository now follows a scalable Playwright structure with dedicated folders for tests, page objects, fixtures, utilities, test data, and reporting.

## Structure

- tests/login
- tests/checkout
- tests/api
- pages
- fixtures
- utils
- test-data
- constants
- visual
- snapshots
- reports

## Commands

- npm test
- npm run test:headed
- npm run lint
